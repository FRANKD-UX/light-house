# Submission checklist

Official rules reviewed 2026-11-24: [Codegeist 2026 rules](https://codegeist2026.devpost.com/rules). Release target 19 December; deadline 22 December 2026 22:00 SAST (12:00 PST). Recheck rules before submission.

- [ ] Owner verifies entrant/team eligibility, representation, geography, employment/conflict restrictions and original IP rights.
- [ ] Select Apps for Specialized Industries and explain ISP-specific context/impact.
- [ ] Working Forge app with manifest/module and genuine Atlassian integration; test functionality beyond one fixture path.
- [ ] Obtain real installation link through authorised production release/sharing; independently test on judge-style site.
- [ ] Provide English configuration instructions, fixtures and any required integration setup; no private ISP access required.
- [ ] Provide English feature/technology description and accurate live versus simulated boundaries.
- [ ] Publish public YouTube demo under five minutes showing the app functioning and real JSM issue creation.
- [ ] Review recording/assets for secrets, personal data, unlicensed trademarks/music/material and employer content.
- [ ] Validate duplicate/recovery/policy-change sequence and clean installation with minimum scopes.
- [ ] Complete Devpost fields, test links/access and submit before the deadline; retain submission confirmation.

These are release/submission gates, not completed Sprint 0 features. AI/Rovo/MCP bonus categories are not pursued under the approved no-runtime-AI scope. Marketplace publication is optional and must not delay a working installation link. The owner must approve any actual submission/publishing action separately.
