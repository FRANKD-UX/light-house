# Judging alignment

Official rules reviewed 2026-11-24 at [Codegeist](https://codegeist2026.devpost.com/rules). The five criteria are equally weighted; Stage 1 first checks viability/platform/theme fit. Sprint 0 is a foundation, not a competition-ready product.

| Criterion                    | Light House evidence to demonstrate later                                                                                                                                                       |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Technological implementation | Real Forge/JSM flow, durable identity/reconciliation, varied validated monitoring events and historical policy snapshots.                                                                       |
| Design                       | Coherent NOC journey: source receipt, impact/uncertainty, deadline, issue and recovery with honest blocked states.                                                                              |
| Potential impact             | Explain how ISP teams move from infrastructure noise to customer/service impact and accountable response deadlines. Use synthetic measured scenario timings; do not invent operational savings. |
| Innovation/idea              | ISP topology, failover and SLA context beyond webhook forwarding; distinguish duplicate suppression from future topology correlation.                                                           |
| Presentation                 | Clear problem/audience, under-five-minute working demo, accurate live/fixture labels and exerciseable installation instructions.                                                                |

Minimum submission scope is in requirements and roadmap. Zoho and optional advanced integrations cannot displace authenticated ingestion, enrichment, actual JSM creation and recoverable lifecycle.
